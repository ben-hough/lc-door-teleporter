# DoorTeleporter

Terminal commands that teleport **you** in front of a random facility door (main entrance or a fire exit).

## Commands

- `DOORPORT` / `DTP` / `EXITPORT` / `FIREEXIT` / `RANDOMEXIT`

Appears on the main terminal help list as `>DOORPORT`.

Only outside entrances (`isEntranceToBuilding`) are used. Config can toggle main vs fire exits.
